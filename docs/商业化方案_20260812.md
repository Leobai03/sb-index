# SB Index 商业化方案

## 结论先行

原版 SBTI 本身没有赚钱。它免费、免注册、约 31 道题，创作者明确表示“不用于盈利”，爆红后很快删除了原视频和网页。真正赚钱的是随后出现的测试平台与复刻产品：利用免费测试获取流量，再卖深度报告、激励广告、私域线索和品牌定制。

我们的策略不是在答题中途收门票，而是：

> 免费测试与基础结果负责传播，付费深度报告负责收入，品牌定制负责利润。

## 调研证据

1. [湖南日报新媒体：SBTI 测试撬动亿级流量](https://m.voc.com.cn/xhn/news/202604/32413325.html)：原版无需注册、不用付费；作者明确表示“不用于盈利”。文章同时总结了行业常见模式：基础结果免费，深度报告付费 9.9—199 元；或看 15—30 秒广告解锁。
2. [中国新闻周刊：做完心理测试，他被骗了 14 万](https://www.inewsweek.cn/finance/2026-04-21/29873.shtml)：确认原作者没有营利；镜像站通过添加微信、付费解锁和订阅实现引流变现，也提醒自动续费和误导收费的风险。
3. [SBTI Premium Report](https://sbtitestpersonality.com/pricing/)：海外复刻产品采用“测试、类型结果、分享卡免费；15 维深度报告与匹配分析 9.99 美元一次性购买”的结构。
4. [腾讯广告小程序变现指引](https://training.tencentads.com/uploads/202406/MdmftG8s_4BW7jO.pdf)：官方建议短流程产品在中后段使用激励视频解锁增值内容，并先露出价值再要求观看广告。

## 收入结构

### 1. 个人深度报告：首发 ¥9.9

免费提供：

- 傻逼指数与主人格
- 一句毒舌解释
- 六维雷达
- 分享海报

付费提供：

- 全部九组“嘴上—行为”对账
- 16 种人格成分完整解释
- 30 天反拧巴行动清单
- MBTI × SB 双人格组合解读
- PDF / 长图保存

定价实验：`¥6.9 / ¥9.9 / ¥14.9` 三档，仅改变价格，不改变内容。首轮默认 ¥9.9，不做自动续费。

### 2. 双人报告：¥19.9

情侣、合伙人、同事各自完成一次测试，生成“谁嘴更硬、谁行动更诚实、最容易在哪类事情上互相折磨”的关系报告。它比单人报告更有分享动机，也天然带来第二位新用户。

### 3. 品牌定制：¥4,999 起

- 定制 12—24 道题
- 定制 6—12 种品牌人格
- 联名结果海报
- 活动数据看板
- 独立域名或小程序版本

适合招聘活动、品牌发布会、社群运营、校园活动。品牌定制是早期现金流主力，不依赖海量 DAU。

### 4. 小程序激励广告：流量放大后再接

网页版本不在答题过程插广告，避免破坏传播漏斗。日完成测试达到 5,000 以后，再上线微信/抖音小程序：基础结果直接看，激励视频只用于解锁一个增值模块或高清海报。

## 已落地的代码

- 结果页新增 ¥9.9 深度报告转化区。
- 支持 `VITE_CHECKOUT_URL` 接微信支付聚合页、Stripe Payment Link 或 Creem。
- 支持 `VITE_BUSINESS_URL` 接飞书表单、企业微信或商务咨询页。
- 已埋点：开始测试、完成测试、分享、点击付费、点击商务合作。
- 埋点同时写入本地并发出 `sb-index:funnel` 浏览器事件，方便接 PostHog/Umami。

| 指标 | 目标 |
|---|---:|
| 首页 → 开始测试 | ≥ 45% |

| 完成 → 点击付费 | ≥ 8% |

按 10,000 次完成测试、2% 付费、客单价 ¥9.9 计算，报告收入约 ¥1,980。真正有意义的收入来自双人报告和品牌定制，因此不要把全部希望压在单人小额付费上。
