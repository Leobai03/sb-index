# 知行偏离测试 · 抖音原生小程序

这是与网页版共用题库和计分逻辑的抖音原生小程序 MVP。用户可从抖音短视频锦点直接进入，在抖音内完成答题、看结果和分享。

## 导入

1. 在抖音开放平台创建企业主体小程序，获取 AppID。
2. 把 `project.config.json` 中的 `APPID_PLACEHOLDER` 替换为真实 AppID。
3. 使用抖音开发者工具导入本目录。
4. 编译、真机预览，然后上传提审。

## 题库同步

网页版题库是唯一数据源。修改 `src/data/questions.ts` 或 `src/data/personas.ts` 后执行：

```bash
npm run build:douyin-data
npm run test:douyin
```

## 已落地的原生页面

- 首页：产品钩子、开测、上次结果
- 答题：21 道快速选择题、随机选项顺序、自动跳题
- 结果：SB 指数、抽象人格、三笔知行差距、六维账单、分享
- 人格图鉴：可展开的人格档案
- 说明：算法原理、娱乐声明、隐私说明
